# Design- en frontend-skills

Opgehaald op 19-11-2026 uit de officiële repos. Updaten: opnieuw kopiëren uit de bron.

| Skill | Bron | Licentie | Gebruik |
|---|---|---|---|
| `impeccable` | github.com/pbakaus/impeccable | Apache 2.0 | Ontwerp, critique, audit, polish, animate (`/impeccable audit`, `/impeccable animate` enz.). De CLI-launcher in `scripts/` haalt bij eerste gebruik een binary van de GitHub-releases (met checksum). |
| `taste-skill` | github.com/Leonxlnx/taste-skill | MIT | Strengere esthetiek tegen voorspelbare AI-layouts. De map `assets/` (38 MB beeldmateriaal) is bewust niet meegenomen. |
| `ui-ux-pro-max` | github.com/nextlevelbuilder/ui-ux-pro-max-skill | MIT | Doorzoekbare stijlen, paletten, fonts en UX-regels: `python3 scripts/search.py "<query>" --domain style`. |
| `web-design-guidelines` | github.com/vercel-labs/agent-skills | MIT | Code-review op UX- en toegankelijkheidsregels. |
| `shadcn` | github.com/shadcn-ui/ui | MIT | shadcn/ui-componenten correct gebruiken. |
| `gsap-core`, `gsap-react`, `gsap-scrolltrigger`, `gsap-timeline`, `gsap-performance` | github.com/greensock/gsap-skills | MIT | Scroll-verhalen en animatie met GSAP. |
| `webapp-testing` | github.com/anthropics/skills | Apache 2.0 | Playwright-tests en screenshots van de gebouwde site. |

`frontend-design` (Anthropic) staat al als plugin in de sessie en is hier niet gedupliceerd.
